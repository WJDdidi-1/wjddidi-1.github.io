Visit statistics / 30 October 2026

A small, anonymous counter.

This portfolio records aggregate page views to show a traffic history and a country-level origins map. The portfolio is hosted on GitHub Pages. The counter runs separately on Sites using a Cloudflare Worker and D1 database.

What the counter saves

The date (Asia/Shanghai), an approximate network country code and a page-view count. A random per-page event ID prevents duplicate submission of the same view. It is not reused across visits and expires from the database after two days; aggregate counts remain.

The counter does not save IP addresses, user names, email addresses, precise coordinates, referral URLs or browsing histories. It sets no cookies, uses no browser storage and does not fingerprint visitors. Hosting and network providers process requests under their own policies.

What the numbers mean

Each counted page load is one page view, not a unique person. Refreshes and repeat visits count again. Simple bot filtering is applied, but counts are an approximate public counter, not an audited measurement. The first version of the site had no tracking, so earlier visits cannot be reconstructed.

Location comes from Cloudflare’s approximate request-country metadata. VPNs, proxies and network routing may affect it. The map uses fixed country/region representative points from Natural Earth, not a visitor’s address or precise position. Missing metadata is shown as unknown rather than guessed.

Your choices

Do Not Track and Global Privacy Control signals are respected by the website. JavaScript-disabled browsing is not counted. You can also block the analytics endpoint without affecting the portfolio itself.

Public aggregates

The site displays daily totals and country/region counts publicly. They can be exported as CSV. If the counter is unavailable, the site displays an unavailable state instead of making up numbers. The source code is available in the portfolio’s GitHub repository.
